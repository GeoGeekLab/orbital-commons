# Orbital Commons

**Catalog / orbit / ground relation.**

A standalone GeoGeek Observatory instrument for reading the active orbital field as a relation between catalog objects, propagated position, orbital class, time, and the ground.

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deployment

GitHub Pages deploys automatically from `main` through `.github/workflows/pages.yml`.

Public URL: https://geogeeklab.github.io/orbital-commons/

## Provenance

Extracted into an independent repository from the GeoGeek Lab Observatory in `GeoGeekLab/GeoGeekLab.github.io`.

Data and runtime dependencies remain explicitly attributed in the interface. Third-party data retain their own terms.
